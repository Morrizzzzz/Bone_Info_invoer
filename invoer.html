Voeg een onderzoekscluster met diersoorten en literatuur toe. Elke opgeslagen invoer wordt één commit op GitHub.

De oorspronkelijke Access-export blijft behouden. Nieuwe gegevens verschijnen na de volgende GitHub Pages-publicatie in de zoekfunctie en op de kaart. Invoer is alleen mogelijk met schrijfrechten op de repository.

1. Verbinden met GitHub

Gebruik een fine-grained personal access token, beperkt tot deze repository, met Contents: Read and write. Het token blijft alleen in het geheugen van deze pagina en wordt uitsluitend naar GitHub verstuurd.

Gegevens laden…

2. Onderzoekscluster invoeren

Velden met * zijn verplicht. Laat onbekende coördinaten leeg. Gebruik RD New (EPSG:28992) in meters.

Diersoorten *

Kies minimaal één soort uit de bestaande taxonomielijst. Elke rij is een soortvermelding, geen telling van botten.

Literatuur

Voeg desgewenst één of meer publicaties toe. Vermeld auteur en titel bij elke toegevoegde publicatie.

3. Controleer en sla op

De onderstaande gegevens worden opgeslagen in de repository. Bij een openbare repository zijn de invoer én de commitgeschiedenis openbaar.
